# Saber Dashboard
This website reduces a fencing bout into notations describing each player's actions (where it happened on the strip, whether it succeeded, etc) and uses it to produce a website that analyses their data, showing statistics that may potentially help players with their bouts. 

Data only includes my (Seoha Kim) data with a dummy player (John Doe). 

Visit the website here - https://seohakim158.github.io/SaberDashboard/

*Please note the website design was done by Claude AI, but the actual analysis and data collection process was done by me (Seoha Kim).*
